Exame de nivelamento (aluno vindo de outra escola)

Em vez de testar um grau, o avaliador vai grau a grau desde o primeiro e avança enquanto o aluno cumprir o critério. A plataforma propõe o último grau cumprido e o admin confirma ou ajusta o grau atribuído.

  • Só o admin convoca para nivelamento; não exige requisitos (presenças/tempo) — o aluno é novo na plataforma.
  • Cada grau é avaliado com os seus itens 1 a 1; só se avança para o grau seguinte quando o atual está completo e cumprido. O avaliador pode parar a qualquer momento.
  • Sem «reprovação»: não ativa os 2 meses de intervalo nem dá o XP de «exame feito»; dá XP de «exame aprovado» se ficar com grau.
  • Graus abaixo do atribuído ficam registados como «obtido por nivelamento».
