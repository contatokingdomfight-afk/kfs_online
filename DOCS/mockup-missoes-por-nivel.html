Para decidires

O XP das missões conta para o nível?
Hoje o XP das missões (284 prémios automáticos de «Subir dimensão», por exemplo «Subir Técnico para 7») vai para o XP antigo e não conta para o nível novo. Proposta: juntar «Missões concluídas» às regras de XP, contando os prémios já ganhos, porque foram conquistados de facto. Assim, quem completou missões sobe de nível já hoje.
